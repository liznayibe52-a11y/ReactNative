# 📱 App Fundación ONG — React Native
 
**Autor:** Liz Nayibe Rico Torres
 
---
 
## 📌 Descripción General
 
Aplicación móvil desarrollada con React Native para una fundación ONG. La app busca visibilizar la misión de la organización y conectar a voluntarios, donantes y beneficiarios desde sus dispositivos móviles.
 
---
 
## 🎯 Objetivos del Proyecto
 
- Construir una aplicación móvil funcional desde cero con React Native.
- Aprender y aplicar los fundamentos del desarrollo mobile.
- Documentar el avance semana a semana durante el proceso de desarrollo.
